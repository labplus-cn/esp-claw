## 主要特性

- 气压量程：**300-1100 hPa**（对应海拔 +9000m ~ -500m）
- 温度范围：**-40 ~ +85 ℃**
- 供电
  - VDD(模拟)：**1.7 ~ 3.6 V**
  - VDDIO(IO)：**1.2 ~ 3.6 V**
- 封装：LGA 金属盖，**2.5 × 2.0 × 0.95 mm**
- 精度
  - 相对精度：±0.06 hPa（等效 ±0.5 m）
  - 绝对精度：典型 ±1 hPa
  - 温度精度：±0.5 ℃ (@25℃)
- 测量时间：典型 28 ms，最短 3 ms
- 功耗
  - 高精度模式：60 µA
  - 低功耗：3 µA
  - 待机：<1 µA
- 接口：I2C(最高 3.4MHz)、SPI(最高 10MHz，3 线/4 线)
- FIFO：可存储 32 组压力/温度测量结果，降低 MCU 唤醒频次
- MSL1 等级

### 典型应用

GPS 导航增强、室内外导航、运动穿戴、天气预报、升降速度检测

### 重要注意

颗粒灰尘会影响 MEMS 膜片性能，装配需做好防尘。

## 工作模式

1. **Standby 待机模式**：上电/复位默认模式，不执行测量；寄存器、校准系数均可访问。
2. **Command 指令模式**：写寄存器触发单次压力或温度测量；测量完成自动回到待机，结果存数据寄存器。
3. **Background 后台连续模式**：按照配置的精度、速率连续测量压力+温度；压力测量完成后立刻执行温度测量；可开启 FIFO 缓存 32 组结果。

> 压力测量依赖温度补偿，**压力测量必须同步做温度测量**。

## 硬件接口

### I2C

- 默认从机地址：`0x77`；SDO 引脚拉 GND → 地址变为 `0x76`
- I2C 写：发送从机写地址 → 寄存器地址 → 数据字节 → STOP
- I2C 读：发送从机写地址+寄存器地址，重复 START，发送从机读地址，自动地址递增读数据，主机 NACK+STOP 结束。

### SPI

- CSB 为片选，低有效，芯片内部带上拉；CSB 拉低进入 SPI 模式
- SPI 模式：**Mode3 CPOL=1,CPHA=1**
- 4-wire SPI：CSB、SCK、SDA(MOSI)、SDO(MISO)
- 3-wire SPI：CFG_REG bit0 置 1；SDA 双向数据；SDO 不再作为 MISO，可做中断输出
- SPI 控制字节：bit7=RW(1 读/0 写)，低 7bit 为寄存器地址。

### 中断

- 使用 SDO 引脚作为中断输出；4-wire SPI 模式**不支持中断**。
- 中断源：新测量就绪、FIFO 满；极性可配置；状态读 `INT_STS` 寄存器。

### FIFO 32 级缓存

- 可保存压力/温度测量，FIFO 读出时 LSB 标记测量类型：`1=压力`，`0=温度`。
- 读 PRS_Bn 寄存器即可读出 FIFO 数据，读完自动指针自增；FIFO 空读返回 `0x800000`；FIFO 满会置标志位，可触发中断。
- FIFO 使能位：`CFG_REG bit1 FIFO_EN`；写 RESET 寄存器 `FIFO_FLUSH=1` 清空 FIFO。

## 补偿计算公式

> 原始 ADC 为 24 位补码；系数从 COEF 寄存器读出，为补码格式。

### 缩放因子 kP / kT（过采样率对应）

| 过采样率 | kP / kT |
| --- | --- |
| 1 (single) | 524288 |
| 2 (Low Power) | 1572864 |
| 4 | 3670016 |
| 8 | 7864320 |
| 16 (Standard) | 253952 |
| 32 | 516096 |
| 64 (High Precision) | 1040384 |
| 128 | 2088960 |

#### 温度补偿

```
Traw_SC = Traw / kT
Tcomp(℃) = c0 × 0.5 + c1 × Traw_SC
```

#### 气压补偿

```
Praw_SC = Praw / kP
Pcomp(Pa) = c00
          + Praw_sc × (c10 + Praw_sc × (c20 + Praw_sc × c30))
          + Traw_sc × c01
          + Traw_sc × Praw_sc × (c11 + Praw_sc × c21)
```

### 海拔与海平面气压公式

```
Altitude(m) = 44330 × [1 − (P / P0)^(1/5.255)],  P0 = 1013.25 hPa
P0 = P / (1 − Altitude/44330)^5.255
```

> 海平面：ΔP=1 hPa 对应高度变化约 8.43 m；高度变化 10 m 对应气压约 1.2 hPa。

| TMP_CFG | 0x07 | R/W | 温度过采样 TMP_PRC、速率 TMP_RATE，TMP_EXT | 0x00 |

| CFG_REG | 0x09 | R/W | 中断、移位、FIFO、SPI 模式配置 | 0x00 |

### PRS_CFG(0x06)

- bit7：保留
- bit6-4：`PM_RATE[2:0]` 后台模式压力测量速率 (1-128Hz)
- bit3-0：`PM_PRC[3:0]` 压力过采样倍数

| PM_PRC | 过采样 | 测量时间 ms | 噪声 Pa RMS |
| --- | --- | --- | --- |
| 0000 | 1x | 3.6 | 5 |
| 0001 | 2x | 5.2 | 2.5 |
| 0010 | 4x | 8.4 | - |
| 0011 | 8x | 14.8 | 1.2 |
| 0100 | 16x(标准) | 27.6 | 0.9 |
| 0101 | 32x | 53.2 | 0.5 |
| 0110 | 64x(高精度) | 104.4 | - |
| 0111 | 128x | 206.8 | - |

> **过采样 >8 倍时，CFG_REG 中 `P_SHIFT` 必须置 1。**

### TMP_CFG(0x07)

- bit7 `TMP_EXT`：**必须 =1，使用 MEMS 片上外部温度传感器**；0 为 ASIC 内部传感器。
- bit6-4 `TMP_RATE[2:0]`：温度后台测量速率。
- bit2-0 `TMP_PRC[2:0]`：温度过采样；**>8 倍需要置位 `T_SHIFT`**。

### MEAS_CFG(0x08)

| Bit | 名称 | 说明 |
| --- | --- | --- |
| 7 | COEF_RDY | 1：校准系数就绪，可以读取 |
| 6 | SENSOR_RDY | 1：传感器初始化完成，建议等待此位再启动测量 |
| 5 | TMP_RDY | 1：温度数据就绪；读温度寄存器自动清除 |
| 4 | PRS_RDY | 1：压力数据就绪；读压力寄存器自动清除 |
| 2-0 | MEAS_CTRL | 模式控制 `000` 待机；`001` 单次压力；`010` 单次温度；`101` 连续压力；`110` 连续温度；`111` 连续压力+温度 |

### CFG_REG(0x09)

| Bit | 名称 | 说明 |
| --- | --- | --- |
| 7 | INT_HL | 中断极性：0 低有效，1 高有效 |
| 6 | INT_FIFO | FIFO 满中断使能 |
| 5 | INT_PRS | 压力就绪中断使能 |
| 4 | INT_TMP | 温度就绪中断使能 |
| 3 | T_SHIFT | 温度 >8 倍过采样必须置 1，数据右移 |
| 2 | P_SHIFT | 压力 >8 倍过采样必须置 1，数据右移 |
| 1 | FIFO_EN | FIFO 功能使能 |
| 0 | SPI_MODE | 0=4-wire SPI；1=3-wire SPI |

### INT_STS(0x0A) 中断状态，读后自动清零

- bit2：INT_FIFO_FULL；bit1：INT_TMP；bit0：INT_PRS

### FIFO_STS(0x0B)

- bit1 FIFO_FULL：FIFO 已满
- bit0 FIFO_EMPTY：FIFO 为空

### RESET(0x0C) 只写

- bit7 `FIFO_FLUSH`：写 1 清空 FIFO
- bit3-0 `SOFT_RST`：写入 `0b1001` 执行软件复位，和上电复位行为一致。

### ID(0x0D)

- bit7-4：PROD_ID 产品 ID；bit3-0：REV_ID 版本 ID

### COEF 校准系数地址映射

| 系数 | 起始地址 | 位宽 | 格式 |
| --- | --- | --- | --- |
| c0 | 0x10-0x11 | 12bit | 2 补码 |
| c1 | 0x11-0x12 | 12bit | 2 补码 |
| c00 | 0x13-0x15 | 20bit | 2 补码 |
| c10 | 0x15-0x17 | 20bit | 2 补码 |
| c01 | 0x18-0x19 | 16bit | 2 补码 |
| c11 | 0x1A-0x1B | 16bit | 2 补码 |
| c20 | 0x1C-0x1D | 16bit | 2 补码 |
| c21 | 0x1E-0x1F | 16bit | 2 补码 |
| c30 | 0x20-0x21 | 16bit | 2 补码 |

> 校准系数区共 18 字节（0x10-0x21）。字节拼接（coef[n] = 寄存器 0x10+n）：
> c0 = coef[0]<<4 | coef[1]>>4；c1 = (coef[1]&0x0F)<<8 | coef[2]；
> c00 = coef[3]<<12 | coef[4]<<4 | coef[5]>>4；c10 = (coef[5]&0x0F)<<16 | coef[6]<<8 | coef[7]；
> c01 = coef[8],coef[9]；c11 = coef[10],coef[11]；c20 = coef[12],coef[13]；
> c21 = coef[14],coef[15]；c30 = coef[16],coef[17]。

## 外围电路要点

1. VDD、VDDIO 引脚就近放 0.1 µF 去耦电容。
2. I2C 总线 SDA/SCL 上拉电阻典型 **10 kΩ** 到 VDDIO。
3. SDO 下拉电阻 R3(100kΩ) 到 GND，I2C 地址切换为 `0x76`。
4. 芯片顶部有透气孔，**透气孔不能被焊盘、三防漆、金属覆盖**。
